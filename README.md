## The joke

## Run it

```sh
node main.ts
```

`main.ts` (Node 22, no dependencies) writes the joke deterministically to `/output/entry.txt`, self-checks the gate (one line, 1–200 characters, not only whitespace), then reads the file back and verifies it byte-for-byte.
